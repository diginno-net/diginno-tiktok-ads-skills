# TikTok Ads Creative Review

Review creative using account evidence plus any user-provided video, screenshot, landing page, or copy.

## Flow

1. Use `tiktok-ads-official` for advertiser and object discovery.
2. Use `tiktok-ads-report-insight` if performance data is needed.
3. Read ad-level report and ad metadata:
   - spend
   - impressions
   - clicks
   - CTR
   - CPC
   - CPM
   - video plays
   - 2s watched
   - 6s watched
   - average play
4. If creative assets are not available, state that the review is performance-signal-only.
5. If assets are available, evaluate:
   - first 1-3 seconds hook
   - product clarity
   - offer clarity
   - proof/trust
   - CTA
   - mobile safe zones
   - landing/destination match
6. Recommend reversible tests, not one-shot conclusions.

## Output

- Best current creative signal
- Weak creative signal
- Hypotheses
- Test plan
- Data missing

## Boundaries

- Do not infer fatigue from spend alone.
- Do not infer creative quality from ad names alone.
- Do not reuse customer creative in public examples unless the user explicitly approves.
