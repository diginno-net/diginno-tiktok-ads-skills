# Report Fields

Default dimensions:

- `campaign_id`
- `adgroup_id`
- `ad_id`
- `stat_time_day`

Default metrics:

- `spend`
- `impressions`
- `clicks`
- `ctr`
- `cpc`
- `cpm`
- `conversion`
- `cost_per_conversion`
- `video_play_actions`
- `video_watched_2s`
- `video_watched_6s`
- `average_video_play`

Useful derived metrics:

- 2s watch rate
- 6s watch rate
- spend share
- click share
- impression share

Only calculate derived metrics when denominator is non-zero.
